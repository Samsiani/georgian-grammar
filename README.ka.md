# ქართული გრამატიკის skill-ი

ეს skill-ი Claude-სა და სხვა AI აგენტებს ეხმარება, რომ ქართულად სწორად და ბუნებრივად წერონ.

skill-ი 15 ფაილში დალაგებულ 128 წესს შეიცავს. თითოეულ წესს აქვს:
- ნომერი;
- ნიშნული: `[norm]` (ნორმა), `[convention]` (მიღებული პრაქტიკა) ან `[style]` (სტილი);
- სწორი და არასწორი მაგალითები;
- წყარო.

English: [README.md](README.md)

## რას აკეთებს

- **წერა.** ქართულ ტექსტს ქართული წინადადების აგებულებით წერს და პასუხის გაცემამდე ძირითადი წესებით ამოწმებს.
- **შესწორება.** მხოლოდ ნამდვილ შეცდომებს ასწორებს და თითოეულ ცვლილებას წესის ნომრით ხსნის. სწორ ტექსტს არ ცვლის.
- **ახსნა.** გრამატიკულ კითხვებს წესებზე დაყრდნობით ხსნის. ტესტურ კითხვაში ყველა პასუხს ამოწმებს.
- **თარგმნა.** თარგმნისას აზრს ზუსტად გადმოსცემს: ვინ რა გააკეთა, საით, რა პირობით, რამდენად დარწმუნებით და ვისი ნათქვამია.

## დაყენება

### Claude Code

Claude Code-ში გაუშვით:

```
/plugin marketplace add Samsiani/georgian-grammar
/plugin install georgian-grammar@georgian-grammar
```

### Claude-ის აპლიკაცია (claude.ai, Claude Desktop)

1. [Releases](https://github.com/Samsiani/georgian-grammar/releases/latest) გვერდიდან ჩამოტვირთეთ `georgian-grammar.zip`.
2. Claude-ში გახსენით **Settings → Capabilities** და **Skills** განყოფილებაში ატვირთეთ ფაილი. კოდის შესრულება (code execution) ჩართული უნდა იყოს.

### სხვა აგენტები (Codex და სხვ.)

აგენტის skills საქაღალდეში დააკოპირეთ მხოლოდ `skills/georgian-grammar` საქაღალდე:

```bash
cp -R skills/georgian-grammar ~/.codex/skills/georgian-grammar
```

- ა. არაბულის „ქართული მეტყველების კულტურა“;
