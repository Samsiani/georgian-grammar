# 09 · Postpositions, adverbs, conjunctions, particles, negation

Load this for any postposition, adverb formation, conjunction choice (cause, purpose, condition), particle, or negation question.

Sources: A §2.1.9–2.1.12, §2.2.9 · B §2.1.8–2.1.11 · C "თანდებულები და მათი ფუნქცია", "არ და ვერ", "კი, არ, ნუ" · Ar (via GZ) §3, §6, §9 · LI high-risk zones (cause/purpose, conditionals).

## POSTP-01 · Postpositions attached to a case [norm]

| Postposition | Attaches to | Forms | Meaning |
|---|---|---|---|
| `-ში` | dative minus `-ს` | `სახლში`, `ქალაქში`, `ზამთარში` | in, into; within (time) |
| `-ზე` | dative minus `-ს` | `მაგიდაზე`, `ამაზე`, `სამ საათზე` | on; about; at (clock time) |
| `-თან` | dative; consonant stems drop `-ს` | `ექიმთან`, `სახლთან`, `დედასთან`, `ხესთან` | at, by, with (a person) |
| `-თვის` | genitive | `ბავშვისთვის`, `დედისთვის` | for |
| `-გან` | genitive | `მეგობრისგან`, `ხისგან` | from (a person or source); made of |
| `-კენ` | genitive | `სახლისკენ`, `ზღვისკენ` | toward |
| `-დან` | instrumental: `-იდან` after a consonant or truncated stem, `-დან` after `-ო`/`-უ` and loanwords in `-ი` | `ოთახიდან`, `ხიდან`, `მეტროდან`, `ტაქსიდან`, `დილიდან` | from (a place or time) |
| `-მდე` | adverbial minus `-დ` | `სახლამდე`, `მთამდე`, `საღამომდე` | up to, until |
| `-ვით` | nominative (consonant stems) or extended dative | `კაცივით` / `კაცსავით`, `ცასავით`, `ჩემსავით` | like |
| `-თანავე` | genitive of a verbal noun | `მოსვლისთანავე` | as soon as |

- `მას` keeps its `-ს`: `მასზე`, `მასში` (✗ `მაზე`).
- Personal pronouns stay bare: `ჩემთვის`, `ჩემკენ`, `ჩემგან` (✗ `ჩემსკენ`).
- **`-დან` vs `-გან`:**
  - a place or a time takes `-დან`: `ოთახიდან გავიდა`, `დილიდან საღამომდე`;
  - a person, a source or a material takes `-გან`: `მეგობრისგან მივიღე`, `ხისგან გაკეთებული`.
  - ✗ `მეგობრიდან`.
- **`-ვით`**: ✗ `ჩემივით` → `ჩემსავით`. ✗ `შურდულისავით`, a genitive-looking form, is a gross error.
- **`-მდე`** is standard and `-მდის` is acceptable. ✗ `-მდეს`, ✗ `-მდინ`.
- **Particles** come after the postposition: `სახლშიც`, `ამისთვისაც`, `იქიდანვე`.

## POSTP-02 · `-თვის`, `-გან`, `-კენ` need the genitive [norm]

- ✗ `დედასთვის` → ✓ `დედისთვის`. Likewise `სკოლისთვის`, `ქვეყნისთვის`.
- Truncated and syncopated stems apply: `ფანჯრისკენ`, `სტუმრისგან` (CASE-04, CASE-05).

## POSTP-03 · Free-standing postpositions [norm]

| Case | Postpositions |
|---|---|
| Genitive | `გამო`, `გარდა`, `ნაცვლად`, `შესახებ`, `მიხედვით`, `მიერ`, `შემდეგ`, `წინ`, `უკან`, `ქვეშ`, `ზემოთ`, `გარშემო`, `ირგვლივ`, `ახლოს`, `წინააღმდეგ`, `დროს`, `განმავლობაში`, `მანძილზე`, `მიმართ` |
| Dative | `შორის` (`ნივთებს შორის`, `ჩვენ შორის`); `-თან ერთად` (`მეგობართან ერთად`) |

- Examples: `გაკვეთილის შემდეგ`, `ომის დროს`, `წლის განმავლობაში`, `წესის მიხედვით`, `ამის გამო`.
- Personal pronouns before them stay bare: `ჩემ გარდა`, `შენ შესახებ`, `ჩვენ გამო`, `ჩემ მიერ`.
- Feelings toward someone take a plain genitive, not `-დმი`: `სამშობლოს სიყვარული` (✗ `სამშობლოსადმი სიყვარული`). `-ისადმი` is fine for dedication: `პიროვნებებისადმი მიძღვნილი` (✗ `პიროვნებებზე მიძღვნილი`).

## ADV-01 · Adverbs [norm]

- **Manner adverbs** are the adverbial case of the adjective: `კარგად`, `სწრაფად`, `ლამაზად`, `ქართულად ლაპარაკობს`. ✗ `კარგი მღერის` → ✓ `კარგად მღერის`.
- **Other formants:**
  - `-ივ`/`-ით`: `მარჯვნივ`, `მარცხნივ`, `ირგვლივ`;
  - `-ჯერ`: `ორჯერ`, `ზოგჯერ`, `ერთხელ`;
  - reduplication: `ნელ-ნელა`, `ფეხდაფეხ`.
- **Place:**
  - `აქ` (here, by me), `მანდ` (there, by you), `იქ` (there);
  - `აქეთ` / `იქით` (this way / that way);
  - `აქედან` / `იქიდან` (✗ `იქედან`).
- **Question and relative pairs:**

| Question | Relative |
|---|---|
| `სად?` | `სადაც` |
| `საიდან?` | `საიდანაც` |
| `საით(კენ)?` | `საითკენაც` |
| `სადამდე?` | — |
| `როდის?` | `როცა` / `როდესაც` |
| `როგორ?` | `როგორც` |
| `რატომ?` | — |
| `რისთვის?` | — |
| `რამდენჯერ?` | — |

## CONJ-01 · Coordinating conjunctions [norm]

| Conjunction | Meaning | Note |
|---|---|---|
| `და` | and | |
| `ან`, `ანდა` | or | |
| `თუ` | or | in questions: `ჩაი თუ ყავა?` |
| `მაგრამ` | but | |
| `ხოლო` | while, whereas | formal contrast |
| `კი` | as for | contrastive, stands after the word it contrasts: `ნინო წავიდა, მე კი დავრჩი` |
| `თორემ` | otherwise | |
| `არამედ` | but rather | after a negation: `არა მე, არამედ ის` |
| `ანუ`, `ე.ი.` | that is | |
| `არც… არც` | neither… nor | |
| `როგორც… ისე` | both… and | |

## CONJ-02 · Subordinating conjunctions: pick the right relation [norm]

| Relation | Conjunctions | Example |
|---|---|---|
| "that" (content) | `რომ` | `ვიცი, რომ მოხვალ` |
| cause | `რადგან(აც)`, `ვინაიდან`, `იმიტომ, რომ`, `რაკი` | `ვერ მოვედი, რადგან ავად ვიყავი` |
| purpose | `რათა`, `რომ`, `იმისთვის, რომ` + optative | `დავრეკე, რათა გამეგო` |
| real condition | `თუ`, `თუკი` + indicative | `თუ წვიმა იქნება, დავრჩებით` |
| unreal condition | `რომ` + pluperfect | `რომ მცოდნოდა, გეტყოდი` |
| time | `როცა`, `როდესაც`, `სანამ`, `მას შემდეგ, რაც`, `როგორც კი` | `როგორც კი მოხვალ, დამირეკე` |
| until | `სანამ … არ` | `სანამ არ მოხვალ, არ წავალ` |
| before | `სანამ` (no negation) | `სანამ წავალ, დაგირეკავ` |
| concession | `თუმცა`, `მიუხედავად იმისა, რომ`, `თუნდაც`, `მართალია… მაგრამ` | |
| as if | `თითქოს` | |
| result | `ასე რომ`, `რის გამოც` | |
| comparison | `ვიდრე` (than), `როგორც` (as) | |

- Never use `რათა` for a cause, or `რადგან` for a purpose.
- `რომ` is ambiguous (that / so that / if / when). In formal text use the specific conjunction [style].
- `რომ` can also stand inside a relative clause: `კაცი, გუშინ რომ მოვიდა, …` = `კაცი, რომელიც გუშინ მოვიდა, …`. Both are correct; the `რომ` version is more conversational.

## PART-01 · Particles [norm]

| Function | Particles |
|---|---|
| Question | `ხომ` (tag: `ხომ მოხვალ?`), `განა` (rhetorical), `ნუთუ` (surprise: "can it really be") |
| Also, even | `-ც` (`მეც`), `-ც კი` (`ბავშვმაც კი იცის`), `კიდეც` |
| Still, yet, already | `მაინც`, `ჯერ` (`ჯერ არ მოსულა`), `უკვე` |
| Only | `-ღა` (`ახლაღა`, `ორიღა დარჩა`), `მხოლოდ` |
| Same, right there | `-ვე` (`იქვე`, `მაშინვე`, `იმავე`) |
| Almost | `თითქმის`, `ლამის`, `კინაღამ` |
| Habitual | `ხოლმე`, with the imperfect or conditional |
| Wish | `ნეტავ(ი)` + subjunctive or pluperfect: `ნეტავ აქ იყოს`, `ნეტავ მცოდნოდა` |
| Reported speech | `-ო`, `-მეთქი`, `-თქო` (SYN-07) |
| Answers | `დიახ` (polite), `კი` (neutral), `ჰო` (casual); `არა`, `ვერა` |

- After an answer particle followed by more words, put a comma: `დიახ, ბატონო`, `არა, ვერ მოვალ`. Standing alone, it takes a period.

## NEG-01 · არ, ვერ, ნუ [norm]

| Particle | Meaning | Example |
|---|---|---|
| `არ` | plain negation: didn't / doesn't / won't | `არ მოვედი` (I didn't come) |
| `ვერ` | inability: couldn't / can't | `ვერ მოვედი` (I couldn't come) |
| `ნუ` | prohibition, with the present or future | `ნუ წახვალ!` (VSER-04) |
| `აღარ` / `ვეღარ` / `ნუღარ` | no longer | `აღარ მოვა`, `ვეღარ ვიცანი` |
| `არც` / `ვერც` / `ნურც` | not even, neither | `არც მე ვიცი` |

- English "couldn't, wasn't able to" → `ვერ`. Using `არ` there changes the meaning.
- With `შემიძლია` itself use `არ`: `არ შემიძლია`. Avoid `ვერ შემიძლია`.
- The particle stands before the whole verb, preverb included: `არ დავწერე`, `ვერ გავიგე`.

## NEG-02 · არ vs არა [norm]

- `არ` goes directly before a verb.
- `არა` is used:
  - on its own, as an answer: `არა, ვერ მოვალ`;
  - in contrasts: `არა მე, არამედ ის`, `არა მხოლოდ… არამედ…`.
- ✗ `არა მოვიდა`.

## NEG-03 · Double negation [norm]

- A negative word (`არავინ`, `არაფერი`, `არსად`, `არასოდეს`) can also take `არ` before the verb, and usually it is optional: `არავინ წასულა` = `არავინ არ წასულა`.
- The particle must match the negative word: `არავინ არ`, `ვერავინ ვერ`, `ნურავინ ნუ`, `არსად არ`, `ვერასოდეს ვერ`.
- The verb particle is **required** when the negative word:
  - is separated from the verb: `არსად ისე არ მღერიან`;
  - carries `-ც(ა)`: `ვერაფერსაც ვერ ვხედავ`;
  - is a modifier: `არავითარი დარდი არ ჰქონდა`;
  - is built with `არც` / `ვერც` / `ნურც`: `არცერთი არ მოსულა`.
- Never mix types: ✗ `ვერავინ არ მოვიდა` when inability is meant, ✗ `არავინ ვერ`.
