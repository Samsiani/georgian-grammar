# 12 · Register, etiquette and natural style

Load this when writing anything longer than a sentence, any formal or customer-facing text, emails and letters, UI copy, or translations from English or Russian. Grammar can be perfect and the text still sound foreign. This file is about sounding like a native writer.

Sources: B §2.1.13 (etiquette) · A §2.1.6.18 (respectful verb pairs) · A. Shanidze, *ქართული ენის გრამატიკის საფუძვლები* (`-თ` in greetings) · Ar (via GZ) §5, §9 · LI style-and-lexical-choice, polite forms · GZ register notes.

---

## REG-01 · Pick one register and keep it [style]

| Register | Features |
|---|---|
| **Neutral literary** (default) | standard forms, plain vocabulary, `შენ` or `თქვენ` chosen once |
| **Official and business** | `თქვენ`, precise terms, no slang. Allows `გთხოვთ`, `პატივისცემით`. Avoid stacked passives and `მიერ`. |
| **Academic** | exact terms, neutral verbs, references in parentheses |
| **Conversational** | contracted forms are possible in dialogue, never in formal text |
| **Marketing and UI** | short, concrete and direct. No hype. |

Don't mix registers in one text, and don't switch `შენ` / `თქვენ` for the same reader.

## REG-02 · Polite address and respectful verbs [norm + convention]

- Use `თქვენ` with plural verbs for one respected person (VPER-07).
- **Address someone** with the vocative: `ბატონო გიორგი`, `ქალბატონო ნინო`. ✗ `ბატონი გიორგი,` as an address.
- **Refer to someone** respectfully in the 3rd person with the nominative: `ბატონი გიორგი მოგვიანებით მოვა`.
- **Formal letters:**
  - opening: `პატივცემულო ბატონო გიორგი,`;
  - closing: `პატივისცემით,` + name.
- **Respectful substitute verbs** (B §2.1.13). Use them only in genuinely polite or ceremonial contexts, never in neutral informational prose:

| Plain | Respectful | Notes |
|---|---|---|
| `ხარ` | `ბრძანდებით` | |
| `მოდი` | `მობრძანდით` | |
| `დაჯექი` | `დაბრძანდით` | |
| `შედი` | `შებრძანდით` / `შემობრძანდით` | |
| `ჭამე` | `მიირთვით` | |
| `აიღე` | `ინებეთ` | |
| `გსურს` | `გნებავთ` | |
| `თქვი` | `ბრძანეთ` | |
| `ვარ` | `გახლავართ` | humble 1st person |
| `მოვალ` | `გეახლებით` | humble 1st person |

- Affectionate name forms (`ნინიკო`, `დათუნა`) are for friends and family only.

## REG-03 · Everyday etiquette formulas [convention]

| Situation | Formulas |
|---|---|
| Greeting | `გამარჯობა` for one person addressed as `შენ`. `გამარჯობათ` for several people, or for polite `თქვენ`. Both forms are correct and both are in the orthographic dictionary. Likewise `დილა მშვიდობისა(თ)`, `საღამო მშვიდობისა(თ)`. Reply: `გაგიმარჯოს` / `გაგიმარჯოთ`. Don't "correct" `გამარჯობათ` [norm] |
| Goodbye | `ნახვამდის`, `კარგად იყავით`, `ღამე მშვიდობისა` |
| Thanks | `მადლობა`, `დიდი მადლობა`, `გმადლობთ`; reply `არაფრის`, `რას ბრძანებთ` |
| Apology | `ბოდიში`, `დიდი ბოდიში`, `უკაცრავად`, `მაპატიეთ` |
| Request | `გთხოვთ`, `თუ შეიძლება`, `ხომ ვერ…?`, `შეგიძლიათ…?` |
| Offer | `ხომ არ ინებებთ…?` |
| Meeting someone | `სასიამოვნოა`, `მოხარული ვარ თქვენი გაცნობით` |
| Congratulations | `გილოცავთ` (`დაბადების დღეს გილოცავთ`) |
| Sympathy | `ძალიან ვწუხვარ`, `ვიზიარებ თქვენს მწუხარებას` |
| Agreeing / declining | `სიამოვნებით`, `რა თქმა უნდა`; `სამწუხაროდ, ვერ შევძლებ` |

## STYLE-01 · Write plain, natural Georgian [style]

- Prefer a direct verb to a noun phrase, and a short sentence to a chain of participles.
- Say the thing. Skip English-style openers and filler:

| ✗ Heavy or calqued | ✓ Natural |
|---|---|
| `მნიშვნელოვანია აღინიშნოს, რომ…` | state the point |
| `როდესაც საქმე ეხება…` | `რაც შეეხება…` |
| `ის ფაქტი, რომ…` | omit, or name the thing |
| `…თვალსაზრისით`, `…კუთხით` in every sentence | restructure |
| `დღის ბოლოს` (not about time) | `საბოლოოდ`, `საბოლოო ჯამში` |
| overused `მოცემული` | `ეს`, `წარმოდგენილი` |

- No marketing slogans or hype words in neutral text, and no invented catchphrases.
- Use the `-ა` copula where it is natural: `სახლი დიდია` reads better than `სახლი არის დიდი`. Both are correct.
- Don't translate English articles. "A man came" → `კაცი მოვიდა` (✗ `ერთი კაცი მოვიდა`, unless "a certain man"). "The book" → `წიგნი` (✗ `ეს წიგნი`, unless it points to something).
- Avoid passive and `მიერ` chains (VOICE-02), and repeated subject pronouns (SYN-02).

## STYLE-03 · Fixed-expression calques [norm / style]

| ✗ | ✓ |
|---|---|
| `საქმე იმაშია, რომ` | `საქმე ისაა, რომ` |
| `რაშია საქმე?` | `რა ხდება?` |
| `ადგილი აქვს` | `ხდება` |
| `მიდის საუბარი` | `საუბარია` |
| `მიდის პროცესი` | `მიმდინარეობს` |
| `შეხვედრა შედგა` | `შეხვედრა გაიმართა` |
| `ძალაში რჩება` | `ძალას ინარჩუნებს` |
| `ამინდი შენარჩუნდება` | `ამინდი გაგრძელდება` |
| `ნაყინი გაყიდვაშია` | `ნაყინი იყიდება` |
| `მიმალვაშია` | `იმალება` |

## STYLE-04 · Keep colloquial and foreign fillers out of writing [style]

| ✗ | ✓ |
|---|---|
| `რო` | `რომ` |
| `არი` | `არის` |
| `ხო` | `ხომ` / `ჰო` |
| `ესეიგი` | `ესე იგი`, `ე.ი.` |
| `რავი` | `არ ვიცი` |

- Russianisms (`ვაბშე`, `უჟე`, `კაროჩე`, `ტოჟე`) don't belong in written text.
- Avoid English words where a normal Georgian word exists: `შეხვედრა`, not `მითინგი`, for a meeting.
- Keep an established technical term rather than inventing a word (STYLE-05).

## STYLE-05 · Terms, product names and UI copy [convention]

- Use one term for one concept throughout a text. Don't alternate synonyms for variety in technical writing.
- For a new or technical term, give the Georgian word and add the English once if readers might need it: `ხელოვნური ინტელექტი (AI)`.
- Keep established product and feature names in Latin script, with endings after a hyphen (NAME-03).
- UI labels and buttons usually use the verbal noun: `შესვლა`, `რეგისტრაცია`, `შენახვა`, `წაშლა`, `გაგზავნა`, `გაუქმება`.
- Messages address the user consistently with `თქვენ` (formal) or `შენ` (casual).
