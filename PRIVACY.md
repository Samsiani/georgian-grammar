# Privacy policy

**Georgian Grammar Skill** (`georgian-grammar`). Last updated: 2026-11-27.

## What the plugin is

The plugin is a set of Markdown instruction and rule files. Claude reads them when it writes, corrects, translates or explains Georgian text.

## Data the plugin handles

The plugin collects, stores and sends **no data**. It contains no scripts, servers, MCP connectors, hooks, analytics or network calls. Nothing you write is sent to the plugin's author or to any third party.

## Your text

Claude processes any text you ask it to write, correct or translate under Anthropic's own terms and privacy policy, not under this plugin's. The plugin adds no processing of its own.

## Contact

Questions about this policy: open an issue at <https://github.com/Samsiani/georgian-grammar/issues>.
